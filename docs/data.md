# Data notes

Everything under `data/` is generated by `python -m datagen.generate` from `datagen/spec.py` and is **synthetic**.

| Item | Location | Notes |
|---|---|---|
| Credit agreements + amendments | `data/borrowers/<ID>/agreement/*.txt` | EDGAR Exhibit-10 structure; boilerplate sections contain distractor ratios (pricing grid, ECF sweep, incremental incurrence test). Page markers `[[PAGE n]]`. |
| Quarterly packages | `data/borrowers/<ID>/packages/<period>/{financials,certificate}.pdf` | 4 quarterly columns + LTM; balance sheet; supplemental cash flow; Exhibit D certificate with Schedules 1-2. |
| XBRL company facts | `data/borrowers/<ID>/xbrl_companyfacts.json` | Mirrors data.sec.gov companyfacts; as-filed values per period plus restated comparatives. |
| Injection twins | `data/twins/` | Same numbers as the injected certificates, without the injected text. |
| Answer key | `data/gold/answer_key.json` | Computed in `datagen/generate.py` with its own arithmetic, independent of `cov/engine.py`. |
| Extraction gold, KG gold, amendment timeline, retrieval questions | `data/gold/` | Labelled before any pipeline run. |

## Seeded cases (32 test periods)
clean (15), tight headroom (3), add-back over cap (1), add-back not permitted (1), borrower arithmetic error (2), restated prior period (1),
statement/certificate conflict (1), true breach honestly reported (1), stale threshold on certificate (1), missing certificate page (1),
amendment with no effective date (2), units change on one statement page (1), injected instruction in certificate text (1),
injected instruction in a numeric field (1). Two borrowers present EBITDA rounded to $100k to create realistic rounding noise.

## Moving to real filings
`scripts/fetch_edgar.py` pulls Exhibit 10 credit documents and XBRL company facts. Real agreements need `cov/kg_llm.py`
(the rule parser only covers the templated language) followed by team review of every node and edge, and real packages
need `cov/extract_llm.py`. Negotiated add-backs and certificates remain synthetic because they are not public.
